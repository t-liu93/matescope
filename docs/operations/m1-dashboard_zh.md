# M1 Dashboard 使用、升级与验收

> [English — 唯一权威来源](m1-dashboard.md) · **中文**

本指南说明 MateScope 与 TeslaMate 一同安装后 M1 的稳定工作流。它不授权生产部署、数据库授权、镜像发布或回滚。

## 使用 Dashboard

通过配置好的 HTTPS 源登录。选择一次车辆后，用日期选择器选择日历范围。**全部历史**从最早可用记录解析到选定的结束日期；它不受 90 天限制。使用**概览**查看精简最近记录值、周期摘要和最近记录。最近记录值独立于所选周期。

使用**行程**和**充电**打开分页列表、详情及其曲线。返回会恢复车辆、周期、页码、滚动位置和焦点。缺失数据、未结束记录和不可用的可选 PostgreSQL 能力会明确显示；它们不代表零或实时数据。地图或曲线失败时，其摘要和其他区域仍可使用。

## 准备并执行升级

变更镜像前，备份 MateScope 自有数据并记录当前镜像引用。完全沿用已有 Compose 调用，只操作 `matescope` 服务。[Compose 指南](existing-teslamate-compose_zh.md)说明如何保留现有 TeslaMate 项目和卷。

使用既有管理员账号启动新镜像。旧的专用角色下基础历史功能仍可用。审查当前[只读账号指南](postgresql-readonly_zh.md)，然后在单独授权的维护窗口内，为明确指定的专用角色执行其中幂等的最小授权升级。不得由应用执行，不得授予无关表或列。重新测试已保存的 PostgreSQL 连接，并验证新可用的详情、序列和最近值能力。

检查所选车辆、短日期范围、全部历史、摘要及代表性行程和充电详情。若回滚后的旧镜像不能读取新配置，请恢复升级前的 MateScope 备份。恢复会使会话和恢复码失效，保留已启用的验证器，`reset-password` 不会关闭 2FA，而禁用 2FA 仍需明确执行运维 `reset-2fa` 操作。

## 所有者验收走查

使用单独授权的合成或生产目标，并让报告不含真实车辆数据。确认以下预期结果：

1. 概览包含精简最近值、四个摘要位置和最近记录，没有图表墙。
2. 改日期会更新周期摘要和记录，但不会重新定义最近记录值。
3. 全部历史可到达最早记录；夏令时、闰日和跨年范围使用预期的本地日历边界。
4. 摘要到列表到详情再返回会恢复状态。请求未完成时切换车辆，旧响应不能覆盖新选择。
5. 缺失、未结束、地图和曲线数据保留明确的部分/错误状态。未设币种时费用不带臆测的限定。
6. 在手机和桌面上，导航、日期选择、记录访问、主题、语言、键盘焦点、触摸目标和底部安全区均可用，页面不会横向滚动。

浏览器自动化仅为 Chromium 和 WebKit 提供证据。真机行为、生产 schema 兼容性、镜像发布和部署是独立验收状态。
